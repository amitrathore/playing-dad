# Look Ma, I'm Playing Dad

Static redesign of the Playing Dad site for GitHub Pages.

The site is self-contained: all images are stored under `assets/images`, and there are no external font, script, or image dependencies.

## Local preview

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
